# 📘 UnrealMate CLI v1.1.4 — User Guide

**The CLI-first Workflow Toolkit for Unreal Engine Developers**

---

## 🚀 Introduction

UnrealMate is a modern command-line toolkit designed to inspect, validate, and manage local Unreal Engine projects. 

**Current Product Focus:**
- **Stable CLI Core:** The primary value is in the stable, default CLI commands.
- **Local-First:** Designed to manage local project state, config, plugins, and git settings.
- **Reporting:** Export rapid point-in-time snapshots of your project status.
- **Caution:** Commands that change your local state (like `git clean`, `plugin install`, or `asset organize`) explicitly warn you before making mutations.

## 📦 Installation

```bash
# Requirements: Python 3.10+, Git installed and in PATH
# (Unreal Engine 5.0+ is recommended for full feature utility)

# 1. Create a virtual environment (Recommended)
python -m venv venv
.\venv\Scripts\activate

# 2. Install UnrealMate
pip install unrealmate

# 3. Verify installation
python -m unrealmate version
```

## 🎮 First Run & Core Concepts

Most users should start with the core inspection workflows before moving on to mutation commands. Run these from your Unreal project root:

```bash
# General help for the stable surface
python -m unrealmate --help

# 1. Check local readiness (Advisory)
python -m unrealmate doctor

# 2. Review local configuration safely
python -m unrealmate config show

# 3. Scan project assets without mutating files
python -m unrealmate asset scan Content

# 4. Review local project metadata
python -m unrealmate build info .
```

*Note: Use `python -m unrealmate --help-all` to discover experimental, secondary, or mock surfaces not shown in the default menu.*

## 🛠️ Stable Command Groups

### 1. Inspect & Validate
Safe-first local inspection workflows that do not modify your project files.

- **`doctor`**: Run advisory local project readiness checks.
- **`config show / validate`**: Review your `.unrealmate.toml` without risking file writes.
- **`asset scan / duplicates`**: Check content folders for basic stats and likely duplicate files.
- **`build info`**: Review local `.uproject` metadata (Advisory/Starter behavior).
- **`plugin list`**: List all locally installed plugins.

### 2. Change Local State
Mutating workflows. These commands will write to disk or change your project configuration.

- **`config init / set / edit / template`**: Manage your `.unrealmate.toml` settings.
- **`git init / lfs / clean`**: Optimized UE git setup and artifact cleanup.
- **`asset organize`**: Moves assets into standardized directory structures.
- **`plugin install / enable / disable / remove`**: Modifies `Plugins/` directories or `.uproject` files directly.

### 3. Analyze & Export
Generate local point-in-time snapshots and heuristic performance reports.

- **`performance profile / memory / shaders`**: Heuristic analysis. (Note: These are local analytical checks, not authoritative live runtime truths.)
- **`report json / html`**: Dump a snapshot of your project state directly to disk.

## 🧪 Secondary & Experimental Features

UnrealMate contains several surfaces that are strictly **experimental, placeholder, or local-only**. They are available but are not the primary, production-polished workflows:

- **`report dashboard`**: A CLI-launched local web surface for project snapshots. It is experimental and relies on local port availability.
- **`report notify`**: Only writes local log entries. Remote webhook delivery (like Slack/Discord) is not implemented.
- **`build ci-init / docker`**: Generates starter template files (not turnkey/production CI/CD automation).
- **AI Commands (`ai detect-bugs`, `ai nlp`)**: Experimental pattern-matchers that may produce hallucinated or generic results.
- **Marketplace commands**: These are localized mock behaviors.

## ❓ FAQ

**Q: Will UnrealMate damage my existing project?**
A: Inspection and reporting commands strictly read data. Any command categorized under "Change Local State" (like `asset organize` or `git clean`) will mutate files, and current semantics expect you to read the inline warnings or rely on your Git history for rollbacks.

**Q: Does UnrealMate automatically send my data to a server?**
A: No. Workflows like `report notify` or analytics are entirely local-only in this repository.

**Q: Why doesn't the dashboard show live engine data?**
A: The dashboard is an experimental secondary UI meant to render static JSON snapshot data generated by the CLI. It does not interface with the running editor telemetry.
