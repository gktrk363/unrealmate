# 📚 API Reference

This section is for developers who want to use UnrealMate modules in their own Python scripts.

## Core Modules

### `unrealmate.core.ux`
User experience components (Progress bars, colored output, panels).

### `unrealmate.core.config`
Configuration management for `.unrealmate.toml`.

### `unrealmate.core.analytics`
Tracking command usage and project metrics.

### `unrealmate.core.nlp_commands`
`NLPCommandParser` class for interpreting natural language inputs.

### `unrealmate.core.team_dashboard`
`DashboardDataProvider` class for aggregating git statistics.

### `unrealmate.core.performance_profiler`
Tools for profiling project assets and performance settings.
