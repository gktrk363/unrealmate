# 🎨 Kod Stili Rehberi (Code Style Guide)

## Python Standartları
UnrealMate, **PEP 8** standartlarını takip eder.

### Formatlama
- **Satır Uzunluğu:** 88 karakter (Black varsayılanı).
- **Girintileme:** 4 boşluk.
- **Tırnak İşaretleri:** Çift tırnak (`"`) tercih edilir.

### İsimlendirme
- `variable_name`: Snake case
- `ClassName`: Pascal case
- `CONSTANT_NAME`: Upper snake case

## Unreal Engine C++ Standartları
Unreal Engine resmi kodlama standartlarını takip ediyoruz.

- **Prefixler:**
  - `A` for Actors (e.g., `AMyActor`)
  - `U` for Objects (e.g., `UMyObject`)
  - `F` for Structs (e.g., `FMyStruct`)
  - `E` for Enums (e.g., `EMyEnum`)
